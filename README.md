# Synergy ChatBot

Простой чат-бот для Университета «Синергия», разработанный на Python с использованием библиотеки NLTK.

## Возможности

- Распознавание ключевых слов
- Ответы на вопросы абитуриентов
- Работа в консоли
- Использование NLP-библиотеки NLTK
